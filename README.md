# Mood Baker

Repositorio propio de Andrea para el proyecto Mood Baker — **separado de
TBNB a propósito**: es un proyecto suyo, no un cliente de la consultoría, así
que no comparte repo ni ramas con `Agentes` (el repo de TBNB).

**Nombre de marca:** Mood Baker (pivote desde Mood Cookies, confirmado el
2026-11-16 — sin conflictos de marca encontrados, ver `fase-b-plataforma-marca.md`).
**Nombre de este repositorio:** `mood-cookies` (heredado, puede renombrarse
cuando Andrea quiera sin que afecte al contenido).

## Qué es Mood Baker

Marca de repostería creativa que explora una forma distinta de disfrutar de
lo dulce (y, cada vez más, de lo salado de temporada): ingredientes de
proximidad, recetas propias, producto de temporada y mucho sabor. El
mecanismo central es **Ritualizar** — no se trata de tener más tiempo, sino
de estar más presentes en el que ya tenemos.

## Cómo está organizada esta carpeta

- `estado.md` — en qué fase va el proyecto, qué está confirmado y qué sigue
  abierto.
- `fase-b-plataforma-marca.md` — propósito, misión, visión, valores, mantra
  borrador, principios de producto y las líneas de producto ya definidas
  (Siempre / Rotacional / Cookies en estudio). Documento vivo — se actualiza
  cada vez que Andrea aporta contenido nuevo, no se reescribe de cero.
- `.claude/agents/` — especialistas de Claude Code para identidad visual,
  diseño aplicado y web, pensados en la misma lógica que usa TBNB con sus
  clientes (ver `lokal-*` en el repo de TBNB como referencia de metodología,
  sin copiar contenido de un cliente real a este proyecto).

## Metodología

Se sigue la misma lógica de fases que TBNB usa en sus proyectos de marca
(Fase A · Investigación → Fase B · Plataforma de marca → Fase C · Diseño del
ecosistema), adaptada: este proyecto empezó directamente en Fase B a partir
del brief de Andrea, sin una Fase A de investigación de mercado formal — ver
`estado.md` para el porqué y si hace falta cubrirla más adelante.
